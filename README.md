# WynnCraft Translate for Russia — файлы перевода

Тут лежат JSON-файлы с русским переводом для мода **WynnCraft Translator** (Fabric, Minecraft 1.21.11). Мод сам подтягивает отсюда свежие переводы, так что обновлять сам мод ради каждой правки не надо.

## Как это работает

Когда вы заходите в мир Wynncraft, мод тихо скачивает `translations/manifest.json` — это список файлов с хэшами. Если что-то поменялось, в чате появится сообщение с кнопками:

- **[Обновить перевод]** — скачает новые файлы в `.minecraft/config/wynncraft_translator/`
- **[Пропустить]** — больше не напоминать об этом обновлении

После скачивания переводы подхватываются сами, перезапускать игру не нужно. Проверка идёт не чаще раза в час. Если хочется проверить прямо сейчас — команда `/wtupdate check`, а скачать можно командой `/wtupdate translations`.

Если вы правили файл в config руками, перед заменой мод сохранит вашу версию рядом как `имя.json.bak`, так что ничего не потеряется.

## Что в папке `translations/`

| Файл | Что внутри |
|---|---|
| `quests.json` | квесты |
| `items.json` | предметы |
| `phrases.json` | фразы и диалоги |
| `npc.json`, `npc_name.json` | NPC и их имена |
| `npc_menus.json` | меню NPC |
| `character_info.json` | информация о персонаже |
| `map_locations.json` | названия локаций на карте |
| `manifest.json` | список файлов с хэшами, мод читает его первым |

## Если хотите поправить перевод

1. Отредактируйте нужный файл в `translations/`. Следите, чтобы JSON остался валидным, битые файлы мод просто не примет.
2. Пересчитайте `manifest.json`: у изменённого файла новые `sha256` и `size`, а `version` нужно увеличить на 1. Если версию не поднять, игроки, которые нажали «Пропустить», новое обновление не увидят.
3. Залейте файл и манифест одним коммитом.

Хэш и размер считаются по самому файлу, поэтому любая правка, даже лишний пробел, меняет хэш. Если хэш в манифесте не совпадёт с файлом, мод откажется его скачивать.

Хэш проще всего посчитать так:

```
python tools/generate_manifest.py
```

(скрипт лежит в репозитории с инструментами, если его тут нет — считайте SHA-256 любым удобным способом, например `Get-FileHash файл.json -Algorithm SHA256` в PowerShell).

## Нашли ошибку в переводе?

Откройте Issue или напишите, что именно не так и где вы это увидели (квест, предмет, NPC). Скриншот сильно поможет.
