# WynnCraft Translate for Russia — файлы перевода

Тут лежат JSON-файлы с русским переводом для мода **WynnCraft Translator** (Fabric, Minecraft 1.21.11). Мод сам подтягивает отсюда свежие переводы, так что обновлять сам мод ради каждой правки не надо.

## Как это работает

Когда вы заходите в мир Wynncraft, мод тихо скачивает `translations/manifest.json` — это список файлов с хэшами. Если что-то поменялось, в чате появится сообщение с кнопками:

- **[Обновить перевод]** — скачает новые файлы в `.minecraft/config/wynncraft_translator/`
- **[Пропустить]** — больше не напоминать об этом обновлении

После скачивания переводы подхватываются сами, перезапускать игру не нужно. Проверка идёт не чаще раза в час. Если хочется проверить прямо сейчас — команда `/wtupdate check`, а скачать можно командой `/wtupdate translations`.

Если вы правили файл в config руками, перед заменой мод сохранит вашу версию рядом как `имя.json.bak`, так что ничего не потеряется.

## Что в папке `translations/`

| Файл | Что внутри |
|---|---|
| `quests.json` | квесты |
| `items.json` | предметы |
| `phrases.json` | фразы и диалоги |
| `npc.json`, `npc_name.json` | NPC и их имена |
| `npc_menus.json` | меню NPC |
| `character_info.json` | информация о персонаже |
| `map_locations.json` | названия локаций на карте |
| `manifest.json` | список файлов с хэшами, мод читает его первым |

## Как обновить перевод

Ничего считать и запускать не нужно: `manifest.json` (список файлов с хэшами) создаётся автоматически. Его пересчитывает GitHub Actions сразу после того, как вы меняете что-то в папке `translations/`. Вам остаётся только загрузить сами файлы.

1. **Поправьте нужный файл** в папке `translations/`. Можно прямо на сайте (иконка карандаша на странице файла) или загрузить новую версию через **Add file → Upload files**. Следите, чтобы JSON остался корректным: битые файлы мод не примет.
2. **Сохраните изменения** (Commit changes).
3. **Подождите 10–30 секунд.** GitHub сам запустит задание и пересчитает манифест: обновит хэши и размеры файлов и увеличит `version`. Увидеть это можно во вкладке **Actions**: зелёная галочка означает, что манифест готов, а в списке коммитов появится «Update translations manifest».
4. **Готово.** Игроки получат уведомление при следующем заходе в мир (в течение часа, плюс пара минут на кэш GitHub).

Новый файл, например `ability_translate/mage.json`, добавляется так же: загрузили в `translations/`, и он сам попадёт в манифест.

### Важно

- **`manifest.json` руками не правьте.** При следующем изменении файлов он всё равно будет пересоздан автоматически, и ваши правки затрутся.
- Если вы загрузили файл, а в **Actions** красный крестик, откройте запуск и посмотрите, что за ошибка. Чаще всего дело в битом JSON в одном из файлов: исправьте его и загрузите заново.
- Если вкладки **Actions** нет или она пустая, проверьте, что в репозитории есть файл `.github/workflows/manifest.yml`, а в **Settings → Actions → General** разрешены Actions.

Откройте Issue или напишите, что именно не так и где вы это увидели (квест, предмет, NPC). Скриншот сильно поможет.
