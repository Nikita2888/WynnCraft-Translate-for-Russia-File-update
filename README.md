# WynnCraft Translate for Russia — файлы перевода

Тут лежат JSON-файлы с русским переводом для мода **WynnCraft Translator** (Fabric, Minecraft 1.21.11). Мод сам подтягивает отсюда свежие переводы, так что обновлять сам мод ради каждой правки не надо.

## Как это работает

Когда вы заходите в мир Wynncraft, мод тихо скачивает `translations/manifest.json` — это список файлов с хэшами. Если что-то поменялось, в чате появится сообщение с кнопками:

- **[Обновить перевод]** — скачает новые файлы в `.minecraft/config/wynncraft_translator/`
- **[Пропустить]** — больше не напоминать об этом обновлении

После скачивания переводы подхватываются сами, перезапускать игру не нужно. Проверка идёт не чаще раза в час. Если хочется проверить прямо сейчас — команда `/wtupdate check`, а скачать можно командой `/wtupdate translations`.

Если вы правили файл в config руками, перед заменой мод сохранит вашу версию рядом как `имя.json.bak`, так что ничего не потеряется.

## Что в папке `translations/`

| Файл | Что внутри |
|---|---|
| `quests.json` | квесты |
| `items.json` | предметы |
| `phrases.json` | фразы и диалоги |
| `npc.json`, `npc_name.json` | NPC и их имена |
| `npc_menus.json` | меню NPC |
| `character_info.json` | информация о персонаже |
| `map_locations.json` | названия локаций на карте |
| `manifest.json` | список файлов с хэшами, мод читает его первым |

## Как обновить перевод (порядок действий)

Мод смотрит не на сами файлы, а на `manifest.json`: сравнивает хэши и по ним решает, что изменилось. Поэтому после правки файлов манифест нужно обязательно пересоздать. Делается это так:

1. **Скачайте репозиторий на компьютер.** Кнопка **Code → Download ZIP** (или `git clone`), потом распакуйте.
2. **Поправьте нужные файлы** в папке `translations/`. Следите, чтобы JSON остался корректным: битые файлы мод не примет.
3. **Пересоздайте манифест.** В корне репозитория выполните:
   ```
   python tools/generate_manifest.py
   ```
   Скрипт сам пересчитает хэши и размеры и поднимет `version` на 1. Старый `manifest.json` удалять не надо, он просто перезапишется. Если файлы не менялись, скрипт так и напишет: «Без изменений».
4. **Залейте на GitHub изменённые файлы и новый `manifest.json` вместе**, одним коммитом. Если залить только файл без манифеста (или наоборот), у игроков будет ошибка Hash mismatch и обновление не скачается.
5. **Проверьте.** Откройте `translations/manifest.json` в репозитории: `version` должен стать больше. Дальше игроки получат уведомление при следующем заходе в мир (не позже, чем через час).

### Если нет Python

Можно и без скрипта, просто это больше ручной работы. Хэш считается по файлу на вашем компьютере, поэтому сначала файл надо скачать:

1. Скачайте нужный файл (или весь репозиторий архивом) и поправьте его на компьютере. Сохраняйте в UTF-8.
2. Посчитайте хэш этого же файла. В PowerShell: `Get-FileHash файл.json -Algorithm SHA256`. Размер в байтах смотрите в свойствах файла (поле «Размер», а не «Размер на диске»).
3. Загрузите на GitHub именно этот файл, не переписывая его заново в редакторе на сайте: редактор может добавить лишний перенос строки в конце, и хэш перестанет совпадать.
4. Откройте `translations/manifest.json` на GitHub (иконка карандаша), впишите новые `sha256` и `size` у этого файла и увеличьте `version` на 1.

### Про версию

Номер `version` нужно поднимать при каждом изменении. Если игрок нажал **[Пропустить]**, мод запоминает номер и не напоминает о нём. Без нового номера он не увидит и следующее обновление.
